# Grilling

AI 코딩 에이전트가 근거와 의존 관계를 바탕으로 의사결정을 검토하도록 돕는 스킬입니다.

Grilling은 체계적인 질문, 반대 관점에서의 검토, 명시적인 확인을 통해 계획, 기술 설계, 아키텍처 결정이 다양한 상황에서도 타당한지 검증합니다.

## 주요 기능

- 의존 관계를 고려한 의사결정 트리
- 라운드별 질의응답
- 근거를 우선하는 기술 조사
- 반대 관점에서의 아키텍처 검토
- 위험 및 상충 관계 분석
- 아키텍처 의사결정 기록(ADR)
- 빠른 검토(Quick), 표준 검토(Standard), 심층 검토(Deep) 모드
- 구현 전 명시적인 승인
